## 1. Executive summary

MediaHub now has a runnable Windows desktop foundation and a working local-library
vertical slice. A user can open the Release executable, click **Automatic Scan**
without selecting a folder, and receive locally indexed movie and episode
candidates. Scans support progress, pause, resume, and cancellation. Indexed data
survives restarts in SQLite.

The work is currently in draft PR #1. It is not merged into main and is not a
packaged production release.

### One-click automatic discovery

- Scan is enabled even when no library root exists.
- Every Scan click discovers new locations before scanning known roots.
- Discovery checks Windows Videos, restricted Desktop and Downloads locations,
  OneDrive media folders, common media folders, ready fixed/removable drives,
  and safe top-level folders that directly contain videos.
- Windows, Program Files, ProgramData, Users, Recovery, Recycle Bin,
  System Volume Information, hidden folders, system folders, and reparse points
  are excluded.
- Discovery has bounded depth and a 500-directory probe budget. It does not
  perform an uncontrolled full-disk crawl.
- Nested candidates are collapsed to prevent parent/child duplicate roots.
- Movies and Series folder names receive a suggested classification; ambiguous
  locations use auto-detect.
- Manual selection remains available for unusual layouts and network shares.

## 5. Known limitations

This is a working vertical slice, not the complete E03 epic or MediaHub 1.0.

- Automatic discovery is intentionally bounded. Deeply nested videos in unusual
  folders may require the manual Settings fallback.
- Real-time FileSystemWatcher monitoring and overflow recovery are not present.
- Scheduled reconciliation scans are not present.
- Missing-file state, rename/move identity, fingerprints, and restored-file
  reattachment are not present.
- FFmpeg/MediaInfo stream probing is not connected.
- Ambiguous matching review and user parsing rules are not present.
- Search has no SQLite FTS index.
- Metadata matching, artwork, generated fallback artwork, and sidecar ingestion
  are not present.
- Playback UI and player-engine integration are not present.
- Root edit, disable, remove, and network-share recovery UI are incomplete.
- Installer, signing, packaging, and update delivery are not present.
- PR #1 is still a draft and is not merged.
