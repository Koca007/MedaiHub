# Security policy

MediaHub treats media files, subtitles, artwork, metadata, network paths, plugins, downloads, and remote payloads as untrusted input.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Use GitHub private vulnerability reporting for this repository when available, or contact the repository owner privately through an established channel. Include affected versions, reproduction steps, impact, and any suggested mitigation.

## Supported state

The project is currently pre-release. Security fixes target the active development branch until stable supported versions are published.

## Sensitive data

Never submit real provider credentials, Supabase service-role keys, database passwords, refresh tokens, network credentials, private notes, or personal media inventories in issues, logs, fixtures, or support bundles.
